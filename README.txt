달스케이프 보컬 가이드
======================

실행 방법
1. ZIP 파일의 압축을 풉니다.
2. index.html 파일을 더블 클릭합니다.
3. 크롬 또는 엣지에서 사이트를 사용합니다.

GitHub Pages 배포 방법
1. GitHub에서 새 저장소(repository)를 만듭니다.
2. index.html 파일을 저장소 최상위에 업로드합니다.
3. Settings → Pages → Build and deployment에서 Deploy from a branch를 선택합니다.
4. Branch를 main, 폴더를 /(root)로 설정하고 Save를 누릅니다.
5. 잠시 기다린 뒤 Pages 화면에 표시된 사이트 주소를 엽니다.

포함된 기능
- 달빛과 밤하늘 테마의 디자인 미리보기 이미지 포함 (dalscape-vocal-preview.png)
- 노래 제목/가수 입력
- 연습 포인트 선택 및 보컬 가이드 표시
- 직접 입력한 짧은 가사 구간의 연습 순서 만들기
- 보컬 기술 설명
- 연습 체크리스트
- 분석 노트와 연습 메모 파일 저장

알려진 제한
- 실제 웹 검색, 스트리밍 서비스 연결, 음원/음성 자동 분석은 포함하지 않습니다.
- 가사 전체를 자동으로 가져오지 않습니다.
- 서버나 데이터베이스가 없어 입력 내용은 여러 기기 간 자동 공유되지 않습니다.

추가 기능: 보컬 기술 페이지에 목 긁는 듯한 거친 음색의 안전 안내, 마이크 녹음/재생, 입력 음량 참고 체크, 자가 연습 체크리스트를 추가했습니다. 녹음은 HTTPS에서 권장됩니다. 자동 체크는 음정·박자·가창력 AI 평가가 아닙니다.

추가 업데이트: 연습 가이드에 연습할 보컬 기술 선택 메뉴를 추가했습니다. 워밍업, 호흡, 음정, 리듬, 발음, 진성/가성, 고음, 비브라토, 감정 표현, 거친 음색, 녹음 피드백을 선택하면 단계별 안내가 표시됩니다.

버전 4 - Android / PC 반응형 화면 지원
- 스마트폰, 태블릿, PC 화면 크기에 맞춰 메뉴와 카드가 자동 배치됩니다.
- 권장: Android Chrome 또는 PC Chrome/Edge 최신 버전.
- 녹음 기능은 브라우저에서 마이크 권한을 허용해야 하며, 보안상 GitHub Pages(HTTPS) 등 HTTPS 주소에서 사용하세요.
- 이 프로그램은 HTML 기반 웹사이트입니다. 별도 설치 앱이 아니라 브라우저에서 열어 사용합니다.
- 실시간 노래 검색, AI 음정/박자 평가는 외부 API/서버 연결이 필요합니다.
