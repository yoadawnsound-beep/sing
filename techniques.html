03 · VOCAL TECHNIQUES

보컬 기술 배우기

목에 무리를 주지 않고 편안한 소리부터 단계적으로 익혀요.

진성

말할 때 목소리와 가까운 소리예요. 편한 음역에서 가볍게 시작하고 목에 힘을 과하게 주지 마세요.

가성

가볍고 부드러운 소리예요. 숨을 과하게 밀지 말고 편안한 음에서 짧게 연결해요.

믹스 보이스

여러 발성 감각을 균형 있게 조절하는 기술이에요. 억지로 흉내 내기보다 천천히 익혀요.

두성·고음

높은 음에서 목을 조이거나 소리를 밀지 마세요. 작은 음량과 낮은 키에서 연습해요.

복식호흡

어깨를 들썩이지 않고 편안하게 숨을 들이마신 뒤, '스—' 소리로 일정하게 내쉬는 연습부터 해요.

비브라토

한 음을 안정적으로 유지하는 것부터 시작해요. 목을 억지로 떨지 말고 자연스러운 울림을 익혀요.

음정 조절

짧은 멜로디를 듣고 따라 부른 뒤 녹음해 비교하세요. 어려우면 키를 낮춰도 괜찮아요.

리듬·발음

가사를 말하듯 읽고 박자를 세어 보세요. 자음은 분명하게, 모음은 자연스럽게 이어 줍니다.

감정·강약

핵심 단어를 정하고 절과 후렴의 강약에 차이를 주세요. 모든 부분을 똑같이 크게 부르지 마세요.

목 긁는 창법 · 거친 음색

거친 음색은 목을 세게 긁거나 조여서 만들지 마세요. 목에 힘을 주지 않은 편안한 말소리와 가벼운 허밍부터 연습하세요.

안전한 순서: 편한 말소리 → 작은 음량의 허밍 → 짧게 녹음해 듣기. 목이 아프거나 쉬거나 기침이 나면 즉시 중단하고 쉬세요.

강한 스크리밍·그로울링은 혼자 무리해서 연습하지 말고, 안전한 발성 지도를 받으세요.

🎙️ 내 목소리 녹음하고 연습 상태 확인하기

마이크로 짧게 녹음한 뒤 재생해 보세요. 아래 체크는 입력 음량에 대한 참고 안내이며, AI가 음정·박자·가창력이나 목소리의 좋고 나쁨을 판정하는 기능은 아니에요.

마이크 권한을 허용해 주세요. 녹음 기능은 HTTPS 주소(예: GitHub Pages)에서 사용하는 것을 권장해요.
